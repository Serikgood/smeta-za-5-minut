# Смета за 5 минут

Веб-приложение для быстрого составления сметы или коммерческого предложения с сохранением в PDF.

Приложение предназначено для предпринимателей, которые готовят коммерческие предложения клиентам, и офисных сотрудников, которым нужно составить смету закупки или показать расходы руководителю.

## Файлы приложения

Планируемая структура:

- `index.html` — структура страницы: поля для ввода, список позиций, итоговая сумма и кнопки.
- `styles.css` — оформление страницы, удобные размеры элементов и адаптация для телефона.
- `script.js` — работа с позициями, расчёт сумм и подготовка документа к сохранению в PDF.

Сейчас созданы только `README.md` и `AGENTS.md`. Файлы приложения будут добавлены по отдельному запросу.

## Как открыть

После создания файлов приложения дважды щёлкните по `index.html`, чтобы открыть его в браузере. Установка программ и запуск сервера не требуются.

## Как проверить

После реализации расчёта добавьте две позиции:

1. Количество — 2, цена — 15 000 ₸. Сумма позиции — 30 000 ₸.
2. Количество — 1, цена — 8 000 ₸. Сумма позиции — 8 000 ₸.

Ожидаемый итог: **2 × 15 000 + 1 × 8 000 = 38 000 ₸**.
